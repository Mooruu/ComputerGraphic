КАК ЗАПУСТИТЬ:

1. Открой Visual Studio

2. Открой файл CGLab4.sln

3. ОБЯЗАТЕЛЬНО ПЕРЕСОБЕРИ ПРОЕКТ:
   - Нажми F7 ИЛИ
   - Меню: Build → Rebuild Solution

   ⚠️ Это КРИТИЧЕСКИ важно! Старый exe не содержит фиксов!

4. Запусти проект:
   - Нажми F5 (с отладкой) ИЛИ
   - Нажми Ctrl+F5 (без отладки)

5. Посмотри логи в Output окне:
   - Меню: View → Output
   - Ищи строки:
     ✅ Texture loaded OK: ... (успех)
     ❌ Texture load FAILED: ... (ошибка)
     FILE NOT FOUND: ... (файл не найден)
