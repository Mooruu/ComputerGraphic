## Как запустить:

1. Открой `CGLab4.sln` в Visual Studio
2. Нажми **F7** чтобы пересобрать проект (ВАЖНО!)
3. Нажми **F5** или **Ctrl+F5** чтобы запустить
4. Смотри в окне **Output** (View → Output) логи загрузки текстур
5. Модель Sponza должна показаться с текстурами!

## Если текстур всё ещё нет:

Смотри в Output окно Visual Studio на строки:
- `✅ Texture loaded OK:` - текстура загрузилась
- `❌ Texture load FAILED:` - текстура не загрузилась
- `FILE NOT FOUND:` - файл не найден
